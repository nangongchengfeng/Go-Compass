## 📚 知识点清单

### 1️⃣ 变量和常量声明

#### 变量声明方式

Go 提供了几种变量声明方式，灵活适应不同场景。

1. **标准声明**：`var 变量名 类型 = 值`（最明确，类型和值都指定）
   ```go
   var name string = "Gopher"
   var age int = 7
   var isHappy bool = true
   ```

2. **类型推断**：`var 变量名 = 值`（编译器自动推断类型）
   ```go
   var city = "北京"      // 自动推断为 string
   var temperature = 25.5 // 自动推断为 float64
   ```

3. **短变量声明**：`变量名 := 值`（最常用，仅在函数内部使用）
   ```go
   name := "Gopher"
   age := 7
   ```
   `:=` 是 Go 的标志性操作符——第一次出现时声明+赋值，之后就是纯赋值了。

4. **批量声明**：（一次声明多个变量，减少重复）
   ```go
   var (
       name  string = "Gopher"
       age   int    = 7
       happy bool   = true
   )
   ```

#### 变量零值

Go 的变量声明后会自动初始化，不会有"垃圾值"。

- 数字类型（int, float）：`0`
- 字符串：`""`（空字符串）
- 布尔：`false`
- 指针、切片、map、函数、接口：`nil`

#### 常量声明

常量是程序运行期间不能改变的值。

```go
const Pi = 3.1415926

const (
    StatusOK       = 200
    StatusNotFound = 404
)
```

常量在编译期就确定了，运行时不能修改。

### 2️⃣ 基本数据类型

Go 的数据类型简洁实用。

#### 整数类型

| 类型 | 大小 | 范围 | 备注 |
|------|------|------|------|
| `int` | 与平台相关 | 与平台相关 | 最常用，64位系统上就是64位 |
| `int8` | 1 字节 | -128 到 127 | 小范围整数 |
| `int16` | 2 字节 | -32768 到 32767 | 中等范围 |
| `int32` | 4 字节 | -2147483648 到 2147483647 | 可存到20多亿 |
| `int64` | 8 字节 | -9223372036854775808 到 9223372036854775807 | 大数字专用 |
| `uint` | 与平台相关 | 0 到与平台相关的最大值 | 无符号正数 |
| `uint8` | 1 字节 | 0 到 255 | 也叫 byte |

**小贴士**：日常开发用 `int` 就够了，有特殊需求时再考虑其他类型。

#### 浮点类型

| 类型 | 大小 | 精度 | 备注 |
|------|------|------|------|
| `float32` | 4 字节 | 约 6 位小数 | 精度较低，慎用 |
| `float64` | 8 字节 | 约 15 位小数 | 最常用，Go 默认浮点类型 |

**小贴士**：浮点数计算有精度问题（如 0.1 + 0.2 ≠ 0.3），涉及金钱计算要小心。

#### 其他类型

- `string`：字符串，UTF-8 编码，支持中文
- `bool`：布尔类型，只有 `true` 和 `false` 两个值

### 3️⃣ if/else 条件判断

Go 的 if/else 必须有大括号，条件两边的括号可选但不推荐。

#### 基本语法

```go
if 条件 {
    // 条件成立执行
}

if 条件 {
    // 条件成立
} else {
    // 条件不成立
}

if 条件1 {
    // 条件1成立
} else if 条件2 {
    // 条件2成立
} else {
    // 都不成立
}
```

**注意**：左大括号 `{` 必须和 if/else 在同一行，不能另起一行。

#### if 带短语句

Go 的 if 可以先声明一个变量，再判断条件，该变量仅在 if/else 块内有效。

```go
if num := 10; num%2 == 0 {
    fmt.Printf("%d 是偶数\n", num)
}
// 这里 num 已超出作用域，无法使用
```

这个特性特别适合处理错误：
```go
if err := doSomething(); err != nil {
    // 处理错误
}
```

### 4️⃣ for 循环

Go 只有 `for` 一种循环，但支持多种写法。

#### 基础 for 循环

```go
for 初始化; 条件; 后处理 {
    // 循环体
}

for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

#### 类似 while 的循环

```go
j := 0
for j < 5 {
    fmt.Println(j)
    j++
}
```

#### 无限循环 + break

```go
k := 0
for {
    if k >= 5 {
        break
    }
    fmt.Println(k)
    k++
}
```

#### continue 跳过

```go
for m := 0; m < 10; m++ {
    if m%2 == 0 {
        continue // 跳过偶数
    }
    fmt.Println(m)
}
```

#### range 循环（遍历数组/切片/Map）

```go
nums := []int{1, 2, 3, 4, 5}
for index, value := range nums {
    fmt.Printf("索引: %d, 值: %d\n", index, value)
}
```

### 5️⃣ switch 语句

#### 基本用法

```go
day := "周一"
switch day {
case "周一", "周二", "周三", "周四", "周五":
    fmt.Println("工作日")
case "周六", "周日":
    fmt.Println("周末")
default:
    fmt.Println("无效的日期")
}
```

#### switch 不带变量（表达式模式）

```go
hour := 14
switch {
case hour < 12:
    fmt.Println("上午")
case hour < 18:
    fmt.Println("下午")
default:
    fmt.Println("晚上")
}
```

#### switch 带短语句

```go
switch n := 15; {
case n%3 == 0 && n%5 == 0:
    fmt.Println("FizzBuzz")
case n%3 == 0:
    fmt.Println("Fizz")
case n%5 == 0:
    fmt.Println("Buzz")
default:
    fmt.Println(n)
}
```

**注意**：Go 的 switch 默认不需要 break，自动结束。

### 6️⃣ FizzBuzz 程序

#### 题目要求

写一个程序，打印 1 到 100 的数字，但是：
- 如果数字是 3 的倍数，打印 "Fizz"
- 如果数字是 5 的倍数，打印 "Buzz"
- 如果数字同时是 3 和 5 的倍数，打印 "FizzBuzz"
- 否则打印数字本身

#### 实现代码

```go
package main

import "fmt"

func main() {
    for i := 1; i <= 100; i++ {
        switch {
        case i%3 == 0 && i%5 == 0:
            fmt.Println("FizzBuzz")
        case i%3 == 0:
            fmt.Println("Fizz")
        case i%5 == 0:
            fmt.Println("Buzz")
        default:
            fmt.Println(i)
        }
    }
}
```

## 📝 练习题（10+ 道）

基础语法光看不行，得动手写！下面这些题覆盖了主要知识点，建议都写一遍。

### 基础练习题

1. **变量练习**：声明 5 个不同类型的变量，打印它们的值和类型（提示：用 `fmt.Printf("%T", 变量)` 可以打印类型）
2. **常量练习**：定义圆周率常量，计算圆的面积和周长（面积=πr²，周长=2πr）
3. **if/else 练习**：写一个程序，判断一个年份是否是闰年（闰年规则：能被 400 整除，或者能被 4 整除但不能被 100 整除）
4. **for 循环练习**：计算 1 到 100 的和
5. **for 循环练习**：打印九九乘法表（要整齐好看哦）
6. **for range 练习**：遍历一个字符串，打印每个字符和它的 Unicode 码点
7. **switch 练习**：根据分数（0-100）打印等级（A: 90-100, B: 80-89, C: 70-79, D: 60-69, F: 0-59）
8. **switch 练习**：根据月份打印该月有多少天（注意闰年 2 月的天数）
9. **FizzBuzz**：完成经典的 FizzBuzz 程序（这个必须会！）
10. **综合练习**：写一个程序，找出 100 以内的所有素数（素数就是只能被 1 和自身整除的数）
