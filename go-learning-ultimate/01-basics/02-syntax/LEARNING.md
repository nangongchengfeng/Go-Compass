# Go 基础语法练习

欢迎来到 Go 语言基础语法的学习笔记！这一节我们会把 Go 的基础语法过一遍，了解它的基本结构和写法。

## 学习目标

看完这一节，你应该能：
- 看懂 Go 程序的基本结构
- 写出一个完整的 Go 程序
- 理解包、导入、函数这些概念
- 掌握基础的声明和使用方式

## 知识点概览

### 1. Go 程序的基本结构

每个 Go 程序都由这些部分组成：

```
┌─────────────────────────────────────┐
│  package main      ← 包声明          │
├─────────────────────────────────────┤
│  import "fmt"      ← 导入包          │
├─────────────────────────────────────┤
│  func main() {     ← 主函数          │
│      fmt.Println("Hello Go!")       │
│  }                                   │
└─────────────────────────────────────┘
```

### 2. 关键点解析

#### 包声明（Package）
- 每个 Go 文件都必须以 `package` 开头
- `package main` 表示这是一个可执行程序（不是库）
- 同一个目录下的文件必须属于同一个包

#### 导入包（Import）
- 使用 `import` 关键字导入需要的包
- 可以单行导入，也可以分组导入：
```go
// 单行导入
import "fmt"
import "os"

// 分组导入（推荐）
import (
    "fmt"
    "os"
)
```

#### 主函数（Main Function）
- `func main()` 是程序的入口点
- 程序启动时会自动调用这个函数
- 它没有参数，也没有返回值

### 3. 基础语法要素

#### 语句和分号
- Go 不需要在语句末尾加分号（编译器会自动加）
- 但如果你想一行写多个语句，可以加分号分隔
- 推荐一行一个语句，更清晰

#### 注释
```go
// 这是单行注释

/*
这是多行注释
可以写很多行
*/
```

#### 标识符命名规则
- 以字母或下划线开头
- 可以包含字母、数字、下划线
- 区分大小写（`Name` 和 `name` 是两个东西）
- 驼峰命名法是主流：`userName`、`calculateTotal`

#### 空白符
- 空格、制表符、换行符都是空白符
- Go 对格式有一定要求，但不像 Python 那么严格
- 用 `gofmt` 工具可以自动格式化代码

## 小提示

1. **使用 gofmt**：写完代码用 `gofmt -w .` 格式化一下，保证代码风格一致
2. **分组导入**：把标准库、第三方库、自己的包分组导入，更清晰
3. **从 main 开始看**：读别人的代码时，先找 `main` 函数，顺藤摸瓜
