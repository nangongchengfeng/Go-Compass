## 📝 知识点 1: 基础函数定义和调用

### 1.1 函数定义格式

Go 语言的函数定义使用 `func` 关键字，格式如下：

```go
// 格式: func 函数名(参数名 参数类型, ...) 返回值类型 {
//     函数体
// }

// 无参数无返回值的函数
func sayHello() {
    fmt.Println("Hello, Go!")
}

// 有参数无返回值的函数
func greet(name string) {
    fmt.Printf("Hello, %s!\n", name)
}

// 有参数有返回值的函数
func add(a int, b int) int {
    return a + b
}
```

### 1.2 函数调用

```go
func main() {
    // 调用函数
    sayHello()
    greet("Gopher")
    
    result := add(3, 5)
    fmt.Println("3 + 5 =", result)
}
```

### 1.3 参数类型简写

如果多个参数的类型相同，可以只写一次类型：

```go
// 完整写法
func add1(a int, b int) int {
    return a + b
}

// 简写写法（推荐）
func add2(a, b int) int {
    return a + b
}
```

### 1.4 函数命名规则

- 函数名首字母大写表示公开（public），可以被其他包调用
- 函数名首字母小写表示私有（private），只能在当前包内使用
- 使用驼峰命名法，如 `calculateArea` 而不是 `calculate_area`

```go
// 公开函数（可以被其他包调用）
func Add(a, b int) int {
    return a + b
}

// 私有函数（只能在当前包使用）
func internalHelper() {
    fmt.Println("这是内部函数")
}
```

## 📝 知识点 2: 多返回值函数

Go 语言的函数可以返回多个值，这在处理错误时特别有用！

### 2.1 基础多返回值

```go
// 返回两个值的函数
func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, fmt.Errorf("除数不能为零")
    }
    return a / b, nil
}
```

### 2.2 调用多返回值函数

```go
func main() {
    result, err := divide(10, 2)
    if err != nil {
        fmt.Println("错误:", err)
        return
    }
    fmt.Println("结果:", result)  // 输出: 5
    
    // 如果不需要某个返回值，用 _ 忽略
    result, _ := divide(8, 2)
    fmt.Println("结果:", result)
}
```

### 2.3 命名返回值

可以给返回值命名，这样在函数体里可以直接使用这些变量：

```go
// 命名返回值
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return  // 裸返回，返回命名的变量
}

func main() {
    a, b := split(17)
    fmt.Println(a, b)  // 输出: 7 10
}
```

## 📝 知识点 3: 变参函数

变参函数可以接受任意数量的参数，使用 `...` 表示。

### 3.1 基础变参函数

```go
// 计算多个数的和
func sum(numbers ...int) int {
    total := 0
    for _, num := range numbers {
        total += num
    }
    return total
}

func main() {
    fmt.Println(sum(1, 2))         // 3
    fmt.Println(sum(1, 2, 3))      // 6
    fmt.Println(sum(1, 2, 3, 4))   // 10
    
    // 也可以传切片，用 ... 展开
    nums := []int{1, 2, 3, 4, 5}
    fmt.Println(sum(nums...))      // 15
}
```

### 3.2 变参和普通参数结合

变参必须是函数的最后一个参数：

```go
// 格式: func 函数名(普通参数, ...变参类型) 返回值
func greetMany(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}

func main() {
    greetMany("Hello", "Alice", "Bob", "Charlie")
}
```

## 📝 知识点 4: 函数作为参数

Go 语言中，函数也是一种类型，可以作为参数传递给其他函数！

### 4.1 函数类型定义

```go
// 定义一个函数类型
type MathFunc func(int, int) int

// 实现这个类型的函数
func add(a, b int) int {
    return a + b
}

func multiply(a, b int) int {
    return a * b
}
```

### 4.2 函数作为参数传递

```go
// 接收函数作为参数的函数
func compute(a, b int, fn MathFunc) int {
    return fn(a, b)
}

func main() {
    result1 := compute(3, 5, add)
    fmt.Println("3 + 5 =", result1)  // 8
    
    result2 := compute(3, 5, multiply)
    fmt.Println("3 * 5 =", result2)  // 15
}
```

### 4.3 匿名函数作为参数

也可以直接传匿名函数：

```go
func main() {
    result := compute(3, 5, func(a, b int) int {
        return a - b
    })
    fmt.Println("3 - 5 =", result)  // -2
}
```

## 📝 知识点 5: 闭包

闭包是一个函数，它引用了函数外部的变量。闭包会"捕获"这些变量，并且会一直持有它们的引用。

### 5.1 基础闭包示例

```go
// 生成累加器的函数
func makeAdder() func(int) int {
    sum := 0
    // 返回一个闭包，这个闭包引用了 sum 变量
    return func(x int) int {
        sum += x
        return sum
    }
}

func main() {
    adder := makeAdder()
    fmt.Println(adder(1))  // 1
    fmt.Println(adder(2))  // 3
    fmt.Println(adder(3))  // 6
    
    // 每个闭包有自己独立的 sum 变量
    adder2 := makeAdder()
    fmt.Println(adder2(10))  // 10
    fmt.Println(adder(4))    // 10（第一个闭包的 sum 继续累加）
}
```

### 5.2 闭包的实际应用 - 计数器

```go
func makeCounter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}

func main() {
    counter1 := makeCounter()
    fmt.Println(counter1())  // 1
    fmt.Println(counter1())  // 2
    fmt.Println(counter1())  // 3
    
    counter2 := makeCounter()
    fmt.Println(counter2())  // 1（独立的计数器）
}
```

## 📝 知识点 6: 简易计算器实战

### 6.1 需求分析

写一个简易计算器，支持：
- 加法 `+`
- 减法 `-`
- 乘法 `*`
- 除法 `/`

### 6.2 参考实现

```go
package main

import (
    "fmt"
    "strconv"
    "strings"
)

// 计算器函数
func calculate(expression string) (float64, error) {
    // 去除空格
    expression = strings.ReplaceAll(expression, " ", "")
    
    // 查找运算符位置
    var op string
    var opIndex int
    for i, c := range expression {
        if c == '+' || c == '-' || c == '*' || c == '/' {
            op = string(c)
            opIndex = i
            break
        }
    }
    
    if op == "" {
        return 0, fmt.Errorf("未找到运算符")
    }
    
    // 解析左右操作数
    leftStr := expression[:opIndex]
    rightStr := expression[opIndex+1:]
    
    left, err := strconv.ParseFloat(leftStr, 64)
    if err != nil {
        return 0, fmt.Errorf("左操作数解析失败: %v", err)
    }
    
    right, err := strconv.ParseFloat(rightStr, 64)
    if err != nil {
        return 0, fmt.Errorf("右操作数解析失败: %v", err)
    }
    
    // 执行计算
    switch op {
    case "+":
        return left + right, nil
    case "-":
        return left - right, nil
    case "*":
        return left * right, nil
    case "/":
        if right == 0 {
            return 0, fmt.Errorf("除数不能为零")
        }
        return left / right, nil
    default:
        return 0, fmt.Errorf("不支持的运算符: %s", op)
    }
}

func main() {
    // 测试
    testCases := []string{
        "3 + 5",
        "10 - 3",
        "4 * 6",
        "15 / 3",
        "10 / 0",
    }
    
    for _, expr := range testCases {
        result, err := calculate(expr)
        if err != nil {
            fmt.Printf("%s = 错误: %v\n", expr, err)
        } else {
            fmt.Printf("%s = %.2f\n", expr, result)
        }
    }
}
```

## 💡 小提示

1. **多返回值是 Go 的特色**，特别适合返回结果+错误
2. **变参函数**用 `...` 表示，可以传任意数量参数
3. **函数也是一种类型**，可以作为参数传递
4. **闭包**会捕获外部变量，每个闭包有自己独立的状态
5. **defer 语句**用于延迟执行，通常用于资源清理（后面会学）
6. **init 函数**在包初始化时自动执行（后面会学）
7. **错误处理**在 Go 中很重要，不要忽略 error 返回值
8. **命名返回值**可以让代码更清晰，但小函数不用也行
9. **匿名函数**适合简单逻辑，不用单独命名
10. **闭包**可以用来实现状态保持、工厂函数等模式
