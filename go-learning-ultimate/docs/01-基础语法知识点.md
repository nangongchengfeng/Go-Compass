## 📝 知识点 1: 变量和常量声明

### 1.1 变量声明方式

Go 语言提供了多种变量声明方式，可以根据实际情况选择合适的方式。

#### 方式 1: 完整声明（var 关键字）
```go
// 格式: var 变量名 类型 = 值
var name string = "Gopher"
var age int = 7
var isHappy bool = true
```

#### 方式 2: 类型推断（可以省略类型）
```go
// Go 会自动根据值推断类型
var name = "Gopher"  // 自动推断为 string
var age = 7          // 自动推断为 int
```

#### 方式 3: 短变量声明（:=）**最常用**
```go
// 只能在函数内部使用
name := "Gopher"
age := 7
city := "北京"
temperature := 25.5
```

#### 方式 4: 批量声明
```go
var (
    name    string = "Gopher"
    age     int    = 7
    isHappy bool   = true
)
```

### 1.2 变量零值

如果声明变量时不给初始值，Go 会自动给它一个"零值"：
- 数字类型：`0`
- 字符串：`""`（空字符串）
- 布尔类型：`false`
- 指针、切片、map、channel、函数：`nil`

```go
var a int         // 0
var b string      // ""
var c bool        // false
var d []int       // nil
```

### 1.3 常量声明

常量使用 `const` 关键字，声明后不能修改。

```go
// 单个常量
const Pi = 3.1415926

// 批量常量
const (
    StatusOK       = 200
    StatusNotFound = 404
    StatusError    = 500
)

// iota 枚举（iota 从 0 开始递增）
const (
    Monday = iota  // 0
    Tuesday        // 1
    Wednesday      // 2
    Thursday       // 3
    Friday         // 4
    Saturday       // 5
    Sunday         // 6
)
```

## 📝 知识点 2: 基本数据类型

### 2.1 整数类型

| 类型   | 范围                          | 占用空间 |
|--------|-------------------------------|----------|
| int8   | -128 ~ 127                    | 1 字节   |
| int16  | -32768 ~ 32767                | 2 字节   |
| int32  | -2147483648 ~ 2147483647      | 4 字节   |
| int64  | -9223372036854775808 ~ ...    | 8 字节   |
| int    | 根据平台决定（32位或64位）    | 4/8 字节 |
| uint8  | 0 ~ 255                       | 1 字节   |
| uint16 | 0 ~ 65535                     | 2 字节   |
| uint32 | 0 ~ 4294967295                | 4 字节   |
| uint64 | 0 ~ 18446744073709551615      | 8 字节   |
| uint   | 根据平台决定（32位或64位）    | 4/8 字节 |
| byte   | 等价于 uint8                  | 1 字节   |
| rune   | 等价于 int32，用于表示 Unicode | 4 字节 |

```go
var (
    intVar     int     = 42
    int8Var    int8    = 127
    int16Var   int16   = 32767
    int32Var   int32   = 2147483647
    int64Var   int64   = 9223372036854775807
    uintVar    uint    = 42
    byteVar    byte    = 'A'
    runeVar    rune    = '中'
)
```

### 2.2 浮点数类型

| 类型     | 精度       | 占用空间 |
|----------|------------|----------|
| float32  | 约 6 位小数 | 4 字节   |
| float64  | 约 15 位小数| 8 字节   |

```go
var (
    float32Var float32 = 3.14
    float64Var float64 = 3.141592653589793
)
```

### 2.3 字符串类型

```go
// 字符串声明
var s1 string = "Hello, Go!"
s2 := "你好，Go！"

// 字符串拼接
s3 := s1 + " " + s2

// 字符串长度
len := len(s1)  // len("Hello") = 5

// 字符串遍历
for i, c := range s2 {
    fmt.Printf("索引: %d, 字符: %c\n", i, c)
}
```

### 2.4 布尔类型

```go
var isTrue bool = true
var isFalse bool = false

// 布尔运算
result1 := true && false  // false（与）
result2 := true || false  // true（或）
result3 := !true          // false（非）
```

## 📝 知识点 3: if/else 条件判断

### 3.1 基础 if/else

```go
score := 85

if score >= 90 {
    fmt.Println("优秀")
} else if score >= 80 {
    fmt.Println("良好")
} else if score >= 60 {
    fmt.Println("及格")
} else {
    fmt.Println("不及格")
}
```

### 3.2 if 带短语句

```go
// 在 if 里声明变量，这个变量只在 if/else 块里有效
if num := 10; num%2 == 0 {
    fmt.Printf("%d 是偶数\n", num)
} else {
    fmt.Printf("%d 是奇数\n", num)
}

// num 在这里已经访问不到了
```

## 📝 知识点 4: for 循环

Go 语言只有 `for` 循环，没有 `while` 或 `do-while`，但 `for` 可以实现各种循环场景。

### 4.1 基础 for 循环

```go
// 格式: for 初始化; 条件; 增量
for i := 0; i < 5; i++ {
    fmt.Printf("%d ", i)  // 输出: 0 1 2 3 4
}
```

### 4.2 类似 while 的循环

```go
j := 0
for j < 5 {
    fmt.Printf("%d ", j)
    j++
}
```

### 4.3 无限循环 + break

```go
k := 0
for {
    if k >= 5 {
        break  // 跳出循环
    }
    fmt.Printf("%d ", k)
    k++
}
```

### 4.4 continue 跳过本次循环

```go
// 只打印奇数
for m := 0; m < 10; m++ {
    if m%2 == 0 {
        continue  // 跳过剩下的代码，直接进入下一次循环
    }
    fmt.Printf("%d ", m)  // 输出: 1 3 5 7 9
}
```

### 4.5 range 遍历（用于数组、切片、字符串、map）

```go
// 遍历字符串
s := "Hello"
for index, char := range s {
    fmt.Printf("索引 %d: %c\n", index, char)
}

// 如果只想要值，不要索引，可以用 _ 忽略
for _, char := range s {
    fmt.Printf("%c ", char)
}
```

## 📝 知识点 5: switch 语句

Go 的 switch 比其他语言更简洁，不需要写 break，自动终止。

### 5.1 基础 switch

```go
day := "周一"

switch day {
case "周一", "周二", "周三", "周四", "周五":
    fmt.Println("工作日")
case "周六", "周日":
    fmt.Println("周末")
default:
    fmt.Println("无效的日期")
}
```

### 5.2 switch 带表达式（不需要 switch 变量）

```go
hour := 14

switch {
case hour < 12:
    fmt.Println("上午")
case hour < 18:
    fmt.Println("下午")
default:
    fmt.Println("晚上")
}
```

### 5.3 switch 带短语句

```go
switch n := 15; {
case n%3 == 0 && n%5 == 0:
    fmt.Println("FizzBuzz")
case n%3 == 0:
    fmt.Println("Fizz")
case n%5 == 0:
    fmt.Println("Buzz")
default:
    fmt.Println(n)
}
```

## 📝 知识点 6: FizzBuzz 经典题目

### 题目描述

写一个程序，打印从 1 到 100 的数字：
- 如果数字是 3 的倍数，打印 "Fizz"
- 如果数字是 5 的倍数，打印 "Buzz"
- 如果数字同时是 3 和 5 的倍数，打印 "FizzBuzz"
- 其他情况，打印数字本身

### 参考实现

```go
package main

import "fmt"

func main() {
    for i := 1; i <= 100; i++ {
        switch {
        case i%3 == 0 && i%5 == 0:
            fmt.Println("FizzBuzz")
        case i%3 == 0:
            fmt.Println("Fizz")
        case i%5 == 0:
            fmt.Println("Buzz")
        default:
            fmt.Println(i)
        }
    }
}
```

## 💡 小提示

1. **短变量声明 `:=` 最常用**，能用就用，代码更简洁
2. **if 里的短语句**很实用，临时变量只在块里有效
3. **switch 不需要 break**，这点比其他语言方便
4. **for 循环万能**，可以替代 while 和 do-while
5. **fmt 格式化输出**常用格式：
   - `%d` - 整数
   - `%f` - 浮点数
   - `%s` - 字符串
   - `%t` - 布尔值
   - `%c` - 字符
   - `%v` - 任意值（万能格式）
