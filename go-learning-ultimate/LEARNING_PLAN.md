## 🎯 核心学习原则

### 70-20-10 原则
- 70% 时间：写代码
- 20% 时间：读源码
- 10% 时间：看书/文档

## 📋 阶段总览

| 阶段 | 名称 | 周期 | 里程碑 |
|------|------|------|--------|
| 1️⃣ | 基础筑基 | 2 周 | 写出 200-500 行 Go 程序 |
| 2️⃣ | 并发编程 | 3 周 | 写出正确的并发程序 |
| 3️⃣ | 进阶原理 | 1 个月 | 阅读并理解标准库源码 |
| 4️⃣ | 工程化 | 1.5 个月 | 完成完整后端服务 |
| 5️⃣ | 云原生与分布式 | 持续 | 参与开源项目 |

## 📚 分阶段详细计划

**具体任务清单：**

## 📝 学习建议

1. **第 1-2 天**：用 v1 的 examples 快速上手，建立信心
2. **第 3 天开始**：按 v2 的 Issue 逐个完成，用 v1 代码作为参考
3. **每周日**：回顾本周学习内容，写学习笔记
4. **项目阶段**：v2 的 Issue 作为需求清单，v1 的代码作为参考实现
